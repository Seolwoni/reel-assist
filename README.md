# Reel Assist

Minecraft 26.2 (Fabric) 낚시 종합 보조 모드 — Made by seolwoni

## 설치
1. [Releases](../../releases)에서 최신 `reelassist-x.x.x.jar` 다운로드
2. `.minecraft/mods` 폴더에 넣기
3. 필요: **Fabric Loader**, **Fabric API** / 권장: **Mod Menu** (설정 화면)

## 기능
- **입질 알림**: 찌가 물면 화면 타이틀 + 띠링 소리
- **자동 낚시 매크로**: 당기기·던지기 각각 1~30틱 랜덤 딜레이 (당기기는 놓치지 않게 최대 17틱), 채팅·인벤토리를 열어도 계속 동작
- **낚싯대 모드 4종** (낚싯대 들고 Shift + 좌클릭으로 변경)
  - 손에 있는 낚싯대 / 손에 있는 낚싯대(파괴보호)
  - 핫바 낚싯대 전부 / 핫바 낚싯대 전부(파괴보호) — 내구도 적은 것부터 사용
- **인벤토리 가득 참**: 매크로 정지 + 타이틀 + 알림음
- **버리기 아이템**: 인벤토리에서 아이템에 마우스를 올리고 `Delete` → 자동으로 버림 (서버 커스텀 아이템도 지원, 완전 일치/이름만/종류만)
- **시선 미세 움직임**: 12~18초마다 ±1도 내외로 부드럽게
- **통계 HUD**: 물고기·보물·쓰레기별 개수, 비율, 마지막 획득 후 시간, 시간당 획득량
- **HUD 위치 편집**: 드래그로 이동, 휠로 크기 조절

모든 설정은 Mod Menu → Reel Assist → 설정에서 바꿀 수 있어요.

> 자동 낚시는 싱글플레이 또는 매크로가 허용된 서버에서만 사용하세요.
